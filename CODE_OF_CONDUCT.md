# Code of conduct

Contributors should communicate respectfully, focus criticism on the work, and
help maintain a welcoming technical community. Harassment, threats, personal
attacks, discrimination, and publishing another person's private information
are unacceptable.

Respect privacy: do not request or share real private keys, wallet files, or
personal/node metadata in issues, reviews, or examples. Technical disagreement
is welcome when expressed with evidence and consideration.

Report conduct concerns to the repository maintainer `ucrem` through an available
private channel; ask for one without posting sensitive details if none is listed.
Maintainers may remove inappropriate content or restrict participation according
to the severity and context of a violation.
