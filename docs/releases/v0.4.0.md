# v0.4.0 — Web Foundation and Dashboard

The explorer now has its first modern website: a server-rendered dashboard that
reads the existing native Ryo API, with readable block/transaction pages, public
height/hash search, a developer guide and additional JSON/raw views.
The old website and templates remain excluded.

## Added

- Next.js, TypeScript, Tailwind and shadcn/ui foundation with bundled fonts/icons,
  persistent light/dark themes and responsive keyboard-accessible navigation.
- Official Ryo logos, a horizontal header and the official website's day/night
  palette, with locally bundled Inter/Montserrat typography.
- Native-reader chain status, exact tip height/difficulty, recent blocks and
  anchored earlier-block navigation with reorg recovery.
- Full-width paired block/confirmed-transaction tables on desktop, stacking on
  mobile; the bounded native TX preview includes coinbase, exact fees and links
  to HTML details and refreshes with the live reader.
- Ten-second live tip checks on the latest dashboard, with pause, hidden-tab
  suspension, bounded reads, last-check time/height and automatic updates
  preserving browser state.
- A block-interval bar chart with numbered block/seconds axes, 1h/24h/7d/30d
  controls and accessible inspection. The hour view labels every block, follows
  the latest bar at the right edge and keeps Y labels visible during scrolling.
  Inspection holds the graph during sync; a top-right "Back to live" button
  resumes following, with no visible scrollbar or range input. An additive bounded native timestamp route
  supplies actual historical windows; signed differences remain intact and
  periods end at the explicitly dated latest available block during sync.
- Readable block headers and paginated transaction lists, with links to native
  transaction details, exact fees, inclusion state, public outputs and ring
  candidate metadata. Hidden output amounts remain explicitly unavailable.
- Global search by block height, block hash or transaction hash, using the
  existing native API rather than a separate index.
- Formatted JSON/raw views inside the explorer layout, with exact token
  preservation, original-view toggle and verbatim downloads.
- A same-origin bounded read-only adapter and a developer API guide.
- Precision/resource tests, production browser accessibility checks and a
  production frontend smoke against native genesis and a limited real mainnet
  sync, including automatic dashboard updates and real spend-transaction pages.

## Changed

- Product metadata advances to 0.4.0; existing API v2 shapes and the supported
  legacy API remain compatible, with the new block-interval window route added.
  Native Ryo crypto and LMDB stay authoritative.
- The full native GitHub Action remains manual-only. No new per-PR or per-merge
  frontend build Action is introduced.

## Upgrade Notes

Rebuild the native server with the existing pinned core and enable `--enable-api-v2`.
Install Node.js 24 LTS, then run `npm ci`, `npm run build` and `npm run start` in
`web/`. Set the server-only `RYO_API_URL` to the native API origin; it defaults to
`http://127.0.0.1:8081`. Keep `--enable-json-api` if legacy clients need that subset.
The website is a separately run Node process; no external database or Docker is
required. See [web operation](../WEB.md) for commands, bounds and deployment scope.

## Known Issues

- Address search, mempool listing, SSE, advanced analytics and local verification
  remain later milestones. Detail input/extra previews have documented display
  bounds; full public DTO and raw responses remain separately available.
- Reader chain data does not establish network-wide synchronization. Independent
  requests can see different heights. Chart timestamps are miner supplied.
- Full-chain capacity, live LMDB mapping growth, external-writer stress, wider
  historical coverage and positive testnet/stagenet fixtures remain unverified.
- Production dependencies have no reported advisories in the recorded audit.
  The developer-only Next ESLint glob dependency includes the unpatched `braces`
  advisory GHSA-vfj7-8cjw-p6xm; no visitor-supplied glob pattern reaches it. See
  the validation report for the exact audit scope.

No public website deployment or packaged binary distribution is included.
